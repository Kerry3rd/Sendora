# SENDORA - Bulk SMS Platform

SENDORA is a powerful bulk SMS platform built for Tanzanian and African businesses. Send messages cheaper than competitors with smart routing (Tanzania → AfricasTalking, International → Twilio).

## Features
- 🇹🇿 **Tanzania-optimized** - 50% cheaper than Twilio for local SMS
- 🌍 **International coverage** - Send globally via Twilio
- 📊 **Real-time delivery reports**
- 👥 **Contact management** with import/export
- 📱 **Campaign creation** with contact selection
- 💰 **Credit system** with M-Pesa integration

## Tech Stack
- Backend: Node.js + TypeScript + Express + PostgreSQL + Redis
- Frontend: React + TypeScript + Material-UI
- SMS: AfricasTalking (Tanzania) + Twilio (International)
